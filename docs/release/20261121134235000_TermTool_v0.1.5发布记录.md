# TermTool v0.1.5 发布记录

发布时间：2026-11-21（Asia/Shanghai）

## 更新内容

- 修复 SSH 终端忽略私钥认证配置的问题，支持私钥文件、passphrase 和 SSH Agent 认证。
- 打包版启动后自动检查更新，并在应用运行期间每 6 小时检查一次。
- 检测到新版时提示用户；支持查看下载进度，并在下载完成后重启安装。
- About 面板显示实际应用版本和更新错误详情。

## 验证情况

- `npm run build:electron`：通过。
- 修改文件 ESLint：通过。
- `git diff --check`：通过。
- 全量 `npm run typecheck`：未通过；仓库已有 8 处未使用变量诊断，均位于本次未修改文件。
- 未对生产 SSH 服务器执行真实连接测试。

## 发布方式

推送 `v0.1.5` 标签后，由 `.github/workflows/release.yml` 构建 macOS、Windows 和 Linux 安装包并创建 GitHub Release。
